# Nano Banana 전체 수정대상 작업팩 v2

- 전체 그림: 360장
- 작업 대상: 144장
- 전면 재생성: 61장
- 부분 수정: 83장
- 유지 가능: 216장

## 사용 순서

1. `00_가이드/나노바나나_전체_수정대상_매니페스트_v2.csv`에서 Priority A부터 정렬한다.
2. `workpack_source`의 원본 PNG를 Nano Banana에 입력한다.
3. `required_correction`과 통합 가이드의 해당 코드 지침을 프롬프트에 사용한다.
4. 결과는 `output_filename` 그대로 저장한다.
5. 원본 픽셀 크기를 유지하고, Part별 제목 정책을 지킨다.
6. Word에서 `그림 변경`으로 교체한 뒤 PDF 렌더 QA를 수행한다.

Part1은 내부 제목 유지, Part2~5는 내부 전체 제목·그림 코드 금지다.
